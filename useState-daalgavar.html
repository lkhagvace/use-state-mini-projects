useState: 3 жижиг даалгавар

Товч дарахад дэлгэц дээрх зүйл өөрчлөгддөг болгоно. Код бэлэн өгөхгүй. Алхмуудыг дагаад өөрөө бич.

useState гэж юу вэ?

React-д «энэ утгыг санаж бай, өөрчлөгдвөл дэлгэцээ дахин зур» гэж хэлэх арга.

const [count, setCount] = useState(0);
countодоогийн утга (уншина)
setCountутгыг өөрчлөх функц
0эхний утга
Яагаад let болохгүй вэ?

let count-ыг өөрчилж болно, гэхдээ React үүнийг мэдэхгүй. Тиймээс дэлгэц шинэчлэгдэхгүй.

setCount бол «утга өөрчлөгдлөө» гэж React-д мэдэгдэх цорын ганц арга.

2 дүрэм
  1. Утгыг зөвхөн set функцээр өөрчилнө.
  2. useState ашигласан файлын хамгийн эхэнд "use client";, дараа нь import { useState } from "react";.

Бэлтгэл

app/components/ хавтсанд 3 файл үүсгэ: Counter.js, LightSwitch.js, SecretMessage.js. Компонент бүр өчигдрийнх шиг export const ... = () => { ... }.

1. 🔢 Тоолуур (Counter.js)

Том тоо, доор нь − ба + товч. Дарахад тоо 1-ээр багасна/нэмэгдэнэ.
  1. Файлын эхэнд юу бичих ёстой вэ? Дээрх 2-р дүрмийг хар.
  2. Тоог хадгалах state үүсгэ. Нэр нь count, эхний утга хэд байх вэ?
  3. Тоог дэлгэцэнд гарга. JS утгыг JSX дотор { }-ээр бичдэгийг санаарай.
  4. + товчинд onClick нэм. Дарахад setCount-д ямар утга өгөх вэ? Одоогийн утга дээр хэдийг нэмэх вэ?
  5. − товч ч яг тийм, зөвхөн хасна.
💡 onClick-д функц өгнө: onClick={() => ...}. () =>-гүй бичвэл товч дарахаас өмнө ажиллачихна.

2. 💡 Гэрэл (LightSwitch.js)

Унтраалттай үед харанхуй дэвсгэр, 🌑, «Асаах» товч. Асаалттай үед шар дэвсгэр, 💡, «Унтраах» товч.
  1. State нь тоо биш, true эсвэл false. Нэр нь isOn. Эхэндээ асаалттай юу, унтраалттай юу?
  2. Товч дарахад эсрэгээр нь болгох хэрэгтэй. JS-ийн «эсрэг» гэдэг оператор аль нь билээ?
  3. Emoji-г ternary-ээр сонго: isOn ? ... : ...
  4. Товчны бичиг, дэвсгэрийн өнгийг (className) ч мөн ternary-ээр сонго.
💡 Нэг товч хоёр ажил хийнэ: асаах ба унтраах. if бичих хэрэггүй, ганц set... хангалттай.

3. 🔒 Нууц мессеж (SecretMessage.js)

«Харах» товч. Дарахад доор нь нууц мессеж гарч, товч «Нуух» болно. Дахин дарахад нуугдана.
  1. Мессеж харагдаж байгаа эсэхийг хадгалах state үүсгэ. Нэр нь isVisible.
  2. Товч дарахад гэрлийнхтэй яг адилхан эсрэгээр нь болгоно.
  3. Мессежийг зөвхөн isVisible үнэн үед харуул. Ternary биш, && ашигла: {{нөхцөл && <p>...</p>}}
  4. Товчны бичгийг ternary-ээр: «Харах» / «Нуух».
💡 Ternary хоёроос нэгийг харуулна. && «харуулах эсвэл юу ч харуулахгүй» үед хэрэглэнэ.

4. page.js

  1. 3 компонентыг import хий.
  2. Хуудсан дээр зэрэгцээ 3 карт болгож тавь. Утсан дээр нэг багана болох ёстой (Tailwind md:grid-cols-3).
  3. Бод: page.js-д "use client" хэрэгтэй юу? Яагаад?
🎯 Дууссаны дараа өөрийнхөөрөө болго

  2. Гэрлийн emoji, өнгийг солих (🌞 / 🌙 гэх мэт).
